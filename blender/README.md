# Blender Workspace

This folder will contain the OxyHeat 3D Blender source structure.

Planned layout:

```text
blender/
├── main/
│   └── OxyHeat_Master.blend
├── equipment/
│   ├── Heater.blend
│   ├── O2_Skid.blend
│   ├── Electrolyzer.blend
│   └── CCUS.blend
├── materials/
├── geometry_nodes/
└── scripts/
```

Binary `.blend` files should be added using Git LFS once modelling starts.

See `docs/05_blender_modeling_standard.md` before creating production geometry.
