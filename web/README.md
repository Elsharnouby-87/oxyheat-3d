# Future Interactive Web Viewer

This folder is reserved for the later **M6 — Interactive Web Digital Twin** phase.

Potential functionality:

- GLB / glTF viewer
- orbit and guided camera modes
- equipment selection
- layer visibility controls
- heater / mixer cutaways
- operating-mode selector
- instrument / process labels
- flow and composition overlays
- optional CCUS / FGR layers

The web application should not be started until the 3D scene hierarchy and export strategy are stable enough to avoid unnecessary rework.
